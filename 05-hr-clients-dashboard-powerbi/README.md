# HR and Clients Dashboard in Power BI

Report: [`dashboard-report.pdf`](dashboard-report.pdf) (exported from Power BI, labels in Portuguese)

## Overview

A 3-page Power BI report that combines client contract data and employee data for a company with offices across Brazil.

- Clients: number of clients and contract value by business area, the highest value client, and average ticket.
- Contracts: contract value by area and criticality level, with conditional formatting.
- Employees: headcount by job level and hiring month, total salaries and taxes, and headcount by state on a map.

Skills: data modelling across client and employee tables, calculated measures (totals, averages, top client), KPI cards, filters by area and region, and map visuals.
